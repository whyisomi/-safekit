# SafeKit — локальное приложение для планирования безопасности на случай ЧП 

**SafeKit** — это приложение для подготовки личного или семейного плана на случай чрезвычайной ситуации. Приложение работает полностью локально в браузере, данные никуда не отправляются.

## Назначение

SafeKit помогает подготовить чек-лист необходимых вещей, сохранить список важных контактов, указать адрес места встречи и добавить личные заметки. Все данные сохраняются только в этом браузере через `localStorage` — никакие данные не отправляются на сервер и не требуют создания аккаунта.

Приложение не содержит выдуманных экстренных номеров, медицинских советов или утверждений, что оно заменяет официальные рекомендации.

## Технологии

- React 19 + TypeScript
- Vite (быстрая сборка и HMR)
- Хранение данных: `localStorage` браузера
- Никаких внешних зависимостей, API или учетных записей

## Использование

Откройте веб-приложение по ссылке: https://whyisomi.github.io/-safekit/

Приложение работает в современном браузере на Windows, Linux, macOS и мобильных устройствах. Pазработка происходит в терминале Linux. 

Данные сохраняются локально в браузере с помощью `localStorage` и не синхронизируются между устройствами.

## Запуск для разработки

```bash
# Установка зависимостей
npm install

# Запуск разработческого сервера
npm run dev

# Открыть браузер по адресу: http://localhost:5173
```

Для сборки производственной версии:

```bash
npm run build
```

Файлы будут находиться в папке `dist/`.

## Где хранятся данные

Все данные хранятся в `localStorage` этого браузера под ключами:
- `safekit-checklist` — чек-лист предметов
- `safekit-contacts` — список контактов
- `safekit-settings` — настройки (адрес встречи, заметки)

**Важно:** Если очистить кэш браузера или переустановить приложение, все сохраненные данные будут потеряны. Рекомендуется periodically экспортировать план в файл JSON (см. ниже).

## Ограничения

- Приложение работает только в браузере, на конкретном устройстве
- При очистке данных браузера или при сбое оборудования план станет недоступен
- Приложение не имеет резервного копирования в облако
- Приложение не заменяет официальные рекомендации органов бедствия
- Некоторые функции (экспорт, печать) работают в современных браузерах

## Функции

1. **Чек-лист необходимых вещей**
   - Категории: Вода и еда, Свет и зарядка, Документы, Одежда и другое
   - Можно добавлять, редактировать, удалять пункты
   - Возможность отмечать пункты как выполненные
   - Указание количества и заметок к каждому пункту

2. **Список важных контактов**
   - Имя, телефон, заметка
   - Пользователь вводит свои контакты (фiktivные номера не предусмотрены)

3. **Поле для заметок и адреса встречи**
   - Адрес места встречи для семьи/группы
   - Свободное поле для личных заметок

4. **Индикатор готовности**
   - Показывает процент выполнения чек-листа
   - Кнопка «Сбросить отметки» для сброса всех галочек

5. **Экспорт и печать**
   - Экспорт плана в файл JSON с полным списком всех данных
   - Версия для печати (открывается в новом окне с удобной типографикой)
   - Данные в экспорте и печатной версии: чек-лист, контакты, настройки

6. **Удаление всех данных**
   - Кнопка с подтверждением для полного удаления всех сохраненных данных
   - Действие необратимо

7. **Пустые состояния и валидация форм**
   - Присутствуют понятные сообщения когда данные еще не добавлены
   - Проверка обязательных полей при добавлении пунктов и контактов
   - Поддержка управления с клавиатуры (tab навигация, Enter/Space для активации)

8. **Адаптация для телефона**
- Интерфейс адаптируется под различные размеры экрана
- Возможность использования на смартфонах и планшетах

## Примеры использования

### Добавление первого пункта в чек-лист
1. Запустите приложение по адресу `http://localhost:5173`
2. Введите название предмета (например, «Бутилированная вода»)
3. Выберите категорию (Вода и еда)
4. Нажмите «Добавить»
5. Повторите для других категорий

### Экспорт плана
1. Нажмите кнопку «Экспорт плана» внизу страницы
2. Будет скачан файл `safekit-plan.json`
3. Файл можно передать другому устройству или сохранить на компьютере

### Печать версии
1. Нажмите кнопку «Печать»
2. Откроется новое окно с удобной типографикой плана
3. Используйте функции печати браузера (Ctrl+P / Cmd+P)

### Удаление всех данных
1. Нажмите кнопку «Удалить все данные»
2. Подтвердите действие во всплывающем диалоге
3. Все данные будут Permanently удалены из localStorage
